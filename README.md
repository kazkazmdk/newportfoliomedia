# newportfoliomedia

Portfolio de Lissandre (celui servi sur [lissandre.github.io](https://lissandre.github.io)), porté sur ce dépôt.

Scène Next.js + React Three Fiber : anneau « Under Construction », matériau de transmission, grille et overlay GitHub / LinkedIn.

## Développement

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
