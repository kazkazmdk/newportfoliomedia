| Site | Emplacement | Origine |
| --- | --- | --- |
| Folio | racine (`app/`, `components/`) | [lissandre.github.io](https://lissandre.github.io) |
| Beyond Memories | `sites/beyond_memories` | [Lissandre/beyond_memories](https://github.com/Lissandre/beyond_memories) |
| Dametis | `sites/dametis` | [Lissandre/dametis](https://github.com/Lissandre/dametis) |
| Skatdesigner | `sites/skatdesigner` | [Lissandre/skatdesigner](https://github.com/Lissandre/skatdesigner) |
