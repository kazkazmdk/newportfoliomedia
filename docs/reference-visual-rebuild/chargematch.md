# ChargeMatch — visual rebuild QA

## REFERENCE

Zaptec stages hardware as premium objects on calm surfaces. Electricity is a designed path, not a table. GearVerify is the functional watt/protocol benchmark.

## CURRENT

Before this pass the concept (hardware bench) was right, but objects were CSS rectangles, the header carried a global PORT / PROTOCOL / POWER strip, and the hero opened on admin selects.

## VISUAL GAP

- Phone / laptop / brick read as prototype blocks.
- Blueprint grid leaked into staging.
- IBM Plex Mono sat on everyday labels.
- Multiport was a secondary panel, not a signature.

## DESIGN DECISION

- Mast: `CHARGEMATCH · DEVICES / KITS / CHECK`. Technical live state only when a result exists.
- Hero is OBJECT → FLOW → PROOF: device, travelling watt line, charger, giant expected W.
- Custom SVGs with volume, ports, lighting, product proportions.
- Compact labeled device/charger/cable/port controls stay in the scene.
- Multiport is a Y-split (`100W → 65W / 35W`) that recomposes when a port is plugged.
- Mono reserved for W, protocol, port IDs.

## REMAINING GAP

Hardware is illustrated SVG, not photographed products. On the captured home the phone/brick still read as silhouettes more than staged objects. Cable geometry is a watt stem. Pair-studio still has more technical rows than a Zaptec product page.
