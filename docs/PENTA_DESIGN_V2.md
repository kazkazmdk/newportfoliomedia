Harsh notes:

- WearThere is finally photographed, but Unsplash contributor names are incomplete because the site HTML is bot-gated. Commons heroes carry the stronger license trail.
- ChargeMatch hardware is original, not official press cutouts. It reads physical; it is not a photographed GaN brick.
- AutoSpec cars are real Commons stills with honest generation labels. Inspection callouts do not fake X-ray locations.
- TripCost is geographic, not a MapLibre tile style. Land is a reduced original polygon; cities use real lat/lon; routes are geodesic and labelled as representation.
- FixCode plate is a conceptual schematic and marked as such. It is not an OEM exploded drawing.

None of these are a clean 9. A 9 would need named Unsplash photographers, official hardware cutouts, and a custom MapLibre style. This pass is 8.6–8.7 craft, not prototype.
